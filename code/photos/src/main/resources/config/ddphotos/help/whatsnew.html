What's New?

Version 1.0.3 - TBD
  • The Publish menu is now the Run menu, since it does more than publish. Its two publishing items are unchanged, apart from Settings... being spelled out as Publish Settings....
  • New Run → Photogen... item, on Cmd-G (Ctrl-G on Windows and Linux). It switches to the Photogen tab and clicks Run for you - handy given how often photogen is rerun after editing a site, an album or your captions.
  • A tab running a command now shows a green lightning bolt, so you can see that run or serve is still up, or watch a publish run move from tab to tab.
  • Menu items now gray out when they can't be used. Rerun Setup Wizard..., Rerun Tour... and the whole Run menu stay out of the way while the setup wizard, the guided tour or a publish run is in progress, rather than interrupting the one you are in the middle of.
Version 1.0.2 - August 7th, 2026
  • New Run menu (called Publish at the time) that publishes a site in one go, instead of running each command yourself. Use Run → Publish Settings... to say what publishing this site means: whether it starts with photogen and build, and whether it finishes with deploy or with export followed by wrangler or surge. Each site remembers its own choice, so they can each publish their own way.
  • Run → Publish... then runs those commands one after another, showing you each tab as it goes. Every step uses the settings you last used on its own tab, so set those up there first. If a step fails, publishing stops on that tab so you can see what happened, and you can publish again once it is sorted out.
Version 1.0.1 - August 4th, 2026
  • Update passwords.yaml when removing an album or changing an album's slug.
Version 1.0.0 - August 3rd, 2026
  • DD Photos 1.0.0 - the first full release, and the end of the betas. Thanks to everyone who tried the beta builds and sent feedback!
  • Links to local servers started in Run and Serve consoles now automatically open.
  • The guided tour now hands the commands to you. Instead of the tour pressing Next to run photogen, run, build and serve, it asks you to click the Run button yourself - the button pulses so it is easy to find - and then follows along. If a command fails, the tour waits so you can fix things and try again.
  • While a tour command is running, the tour explains what to watch for and stays out of the way, so you can browse your site in the dev server for as long as you like before clicking Stop to continue.
  • Stop Tour (formerly Cancel) now asks you to confirm, since several steps ask you to click something in the main window, and it was easy to end the tour by accident.
  • After saving site settings, album settings, photo captions or your custom stylesheet, DD Photos reminds you to rerun photogen to see the changes. The reminder has a don't show this again option.
  • The mouse-over help at the bottom of the window is now yellow on gray, so it is easier to notice.
  • The Edit buttons on the Config tab are now labeled Edit Site and Edit Album, making it clear which side you are editing.
  • Photos that can't be previewed in the caption editor (e.g. HEIC files) now show a tooltip naming the file, rather than just an unexplained placeholder.
  • Clearer wording for an album's Slug, described as the album's name as used in URLs.
Version 1.0.0b8 - July 31st, 2026
  • Added editor for a site's custom stylesheet (custom.css), reached from the new Custom CSS... button in the site details on the Config tab. Rules you put there are loaded after the built-in styles, so they override the defaults.
  • Added editor for deployment settings (site.env), reached from the pencil button beside --site-env on the Deploy tab. It edits the file named in that field, or your [config-folder]/site.env when the field is blank, and creates the file if it doesn't exist yet.
  • Both editors open in their own resizable window, showing the full path of the file being edited and a button to reveal its folder in your file manager.
  • Installer downloads now name the platform, e.g. ddphotos_mac_1_0_0b8.dmg.
  • Clearer help text for Wrangler's --project-name and Surge's --domain, which are names you pick rather than ones DD Photos knows.
  • Surge authentication is now checked with surge account whoami, matching current Surge releases.
  • Fixed --domain, --project-name and --aws-profile being too narrow to show a full value.
Version 1.0.0b7 - July 29th, 2026
  • Added editor for photo captions and manual sort order (photogen.txt file).
  • Added editor for site and albums passwords (passwords.yaml file).
  • New albums are now added above the selected album rather than at the end.
  • On macOS, menus are now available from every window (Help, Support and the photo editor), not just the main window.
  • Undo/redo support in text widgets. Edit menu with undo/redo.
  • Only allow single instance to run at a time.
  • Sharpen image rendering.
  • Refreshed app icon, logo and splash screen.
  • Clearer guidance when Docker isn't running on Linux, covering both Docker Desktop and Docker Engine.
  • Deploy prerequisite checks now tell the difference between "not set up yet" and "the check itself failed". A failed check shows what actually happened instead of offering a fix that won't help. Notably, DD Photos no longer offers to create a Cloudflare Pages project that already exists.
  • The command console now reports how long each command took, both when it finishes and when you stop it.
  • Upgrade now stops with "Cannot upgrade since ddphotos serve is currently running" instead of failing partway through. Docker won't remove the old image while a container is still using it.
  • When a file can't be saved, DD Photos now says which file and why (missing folder, permission denied, read-only location) rather than showing a raw error.
  • sites.yaml, albums.yaml, passwords.yaml and photogen.txt are now written atomically, so a save interrupted by a crash or a full disk can't leave a truncated file.
  • Command console no longer shows raw color codes ([31m) in wrangler output.
  • Fixed caret drifting away from the text you're editing in long fields (e.g. photo captions) on scaled displays. DD Photos now uses your system's UI font rather than a bundled one.
  • Fixed window size restoration when a menu is present (Windows/Linux).
  • Fixed issue where window icons weren't used on Linux.
  • Fixed the site folder showing as invalid when editing a site that uses a custom config path.
